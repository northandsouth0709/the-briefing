What's the difference between A and B?

A bakes the notes straight into the page — simplest, re-host after pasting. B gives you the encrypted file to host separately (the GitHub method): set CONFIG_URL in index.html to its Raw link once, then you only overwrite this file to update — no re-hosting. Either way the file is encrypted; keep your plain reasons.json private.
